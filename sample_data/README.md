# Sample datasets

All files are **synthetic**. They are generated by `scripts/generate_samples.py` with a fixed random seed, so there are no licensing or privacy concerns.

| File | Rows | Highlights |
|---|---|---|
| `sales_orders.csv` | 5,000 | Dates, categories, numeric prices/revenue, ~2% missing `ship_days` |
| `employees.csv` | 1,045 | Missing values in several columns, 30 exact duplicate rows, 15 near-duplicates (differ only by `employee_id`) |
| `air_quality.csv` | 8,760 | Hourly time series for two stations with sensor outages (missing blocks) |

Regenerate with `python scripts/generate_samples.py`.
